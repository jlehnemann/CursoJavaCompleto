# Web Services Project - Spring Boot e JPA/Hibernate

Project developed during "Complete Java Object-Oriented Programming + Projects (Udemy)" course by Nélio Alves,
creating a web service with CRUD operations using Spring Boot and JPA/Hibernate, for learning purposes.
---
## Developed using:
- Java 25
- Maven
- Spring Boot 4.1.1
- H2 Database
- JPA / Hibernate
- IntelliJ IDEA IDE
- DBeaver
---
## Dependencies:
- Automatically managed by Maven by the `pom.xml` file.
